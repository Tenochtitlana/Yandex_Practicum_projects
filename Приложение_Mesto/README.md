# Проект Приложение Mesto от Яндекса
  Приложение **Mesto** это сервис для загрузки и хранения фотографий.

### Описание проекта
  Проект состоит из двух частей: регрессионное тестирование и выявление баг-репортов. В ходе проекта было создано 17 тест-кейсов и проверено 9 багов. 
 
### Задачи регрессионного тестирования
  * Протестировать сервис по готовым тест-кейсам и проставить статусы выполнения проверок.
  * Составить баг-репорты
  * Оформить Пояснительную записку по шаблону

### Задачи ретеста багов
  * Изучить список багов, которые нашли другие тестировщики в сервисе Mesto.
  * Убедиться, что разработчики исправили баги: провести ретест, используя тестовый стенд.

<summary> BUG-MESTO-2: В профиле не обновляются поля "Имя" и "Занятие" после нажатия на кнопку "Сохранить" </summary><br>
	
**Приоритет**: Блокирующий<br>
**Шаги воспроизведения**: 	
1. Кликнуть на строку ввода "Имя"
2. Ввести “Иван”
3. Кликнуть на строку ввода "Занятие"
4. Ввести “Художник”
5. Нажать кнопку “Сохранить”

**ОР**: На главной странице в профиле отображается “Иван” и “Художник” после редактирования<br>
**ФР**: После нажатия на кнопку "Сохранить" профиль остается прежним:  Жак-Ив Кусто, Исследователь океана.
</details>
