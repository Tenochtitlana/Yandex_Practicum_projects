## Описание проекта
Этот проект является расширенной версией проекта Яндекс Маршруты и включает в себя следующие цели:<br>

🚘 **Каршеринг**
   * Составление тестовой документации
   * Выполнение проверок
   * Заведение баг-репортов

 ### Ход выполнения проекта    
<details>
<summary> Подготовка чек-листа на вёрстку полей </summary>
<br>
Необходимо изучить требования и макеты, выбрать для своей работы любой тариф. Также составить чек-лист на вёрстку следующих блоков:<br>
 
   * Форма бронирования;<br>
   * Элементы на навигационной карте.<br>

#### Окружения для всех этапов проекта: <br>

  * Яндекс Браузер, v.25.8.5.983 разрешение экрана 800×600<br>
  * Firefox, v.144.0.2 разрешение экрана 1920×1080<br>
